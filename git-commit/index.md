# Git Commit (Conventional Commits)

Especialidade voltada para a criação de commits padronizados e semânticos no Git, utilizando a especificação do *Conventional Commits*.

## Resumo

1. **Para que serve:** Analisar o diff (diferença) real do código para determinar o tipo, escopo e mensagem apropriados, gerando commits organizados, semânticos e seguros.
2. **Comando de instalação:** `npx skills add github/awesome-copilot/git-commit`
3. **Melhor forma de usar:** Utilizar para analisar alterações (`git diff`), agrupar arquivos logicamente, classificar o tipo de mudança (ex: `feat`, `fix`, `refactor`) e escrever mensagens no modo imperativo com menos de 72 caracteres.
