# Chat UI

Skill focada em fornecer componentes base (building blocks) para a construção de interfaces de chat interativas baseadas no `ui.inference.sh`.

## Resumo

1. Para que serve: Oferecer um conjunto modular de componentes React prontos para uso (contêineres, mensagens, campo de entrada e indicadores de digitação) voltados especificamente para a criação de aplicações de chat e agentes.
2. Comando de instalação: `npx shadcn@latest add https://ui.inference.sh/r/chat.json`
3. Melhor forma de usar: Importando os componentes modulares e compondo a interface do usuário reativamente com base nos estados da aplicação (como `isLoading` para exibir indicadores de digitação e desabilitar inputs temporariamente).
