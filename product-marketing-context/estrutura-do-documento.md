# Estrutura do Documento

## Passo 3: Criar o Documento

1. Após coletar as informações, crie o arquivo `.agents/product-marketing-context.md` com a estrutura exata definida.
2. Inclua o cabeçalho com a data da última atualização.
3. Estruture as seções com títulos Markdown (ex: `## Visão Geral do Produto`, `## Público-Alvo`, `## Personas`, etc.).
4. Utilize tabelas para organizar Personas, Objeções, Glossário e Temas de Valor.
5. Use blocos de citação para os depoimentos na seção de Provas Sociais.

## Passo 4: Confirmar e Salvar

1. Mostre o documento concluído ao usuário.
2. Pergunte se algo precisa de ajuste.
3. Salve o documento no caminho correto (`.agents/product-marketing-context.md`).
4. Informe ao usuário que outras habilidades de marketing usarão esse contexto automaticamente.

## Dicas Adicionais

1. Seja específico nas perguntas (ex: "Qual é a frustração número 1 que os traz até você?").
2. Capture as palavras exatas dos clientes sempre que possível.
3. Peça exemplos para obter respostas melhores.
4. Valide as informações resumindo cada seção antes de avançar.
5. Pule as seções que não se aplicam ao produto (por exemplo, Personas detalhadas para produtos B2C).
