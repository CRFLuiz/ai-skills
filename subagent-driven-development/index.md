# Subagent-Driven Development

Desenvolvimento focado na execução de planos através do envio de subagentes (subagents) para tarefas específicas, garantindo alta qualidade e iteração rápida.

## Resumo

1. **Para que serve:** Delegar tarefas a subagentes especializados com contexto isolado, realizando uma revisão em duas etapas após cada tarefa (conformidade com a especificação e qualidade do código).
2. **Comando de instalação:** `npx skills add obra/superpowers/subagent-driven-development`
3. **Melhor forma de usar:** Utilizar quando se tem um plano de implementação com tarefas independentes na mesma sessão, despachando um novo subagente para cada tarefa para evitar poluição de contexto.
