# Coleta de Contexto e Direção

## Protocolo de Coleta de Contexto

1. As habilidades de design produzem saídas genéricas sem o contexto do projeto. Você DEVE confirmar o contexto antes de fazer qualquer trabalho de design.
2. O contexto obrigatório inclui: público-alvo (quem usa e em qual contexto), casos de uso (que tarefas tentam realizar) e personalidade/tom da marca (como a interface deve ser sentida).
3. É fundamental entender que o contexto não pode ser inferido apenas lendo o código-fonte; o código diz o que foi construído, não para quem ou qual o tom.
4. Ordem de coleta: verifique as instruções atuais; se não houver, leia o arquivo `.impeccable.md` na raiz; se ainda não houver, execute o comando `/teach-impeccable` antes de prosseguir.

## Direção de Design

1. Comprometa-se com uma direção estética OUSADA.
2. Defina o propósito: qual problema a interface resolve e quem a utiliza.
3. Escolha um tom extremo (ex: brutalmente minimalista, caos maximalista, retro-futurista, orgânico, luxuoso, lúdico, etc.). A chave é a intencionalidade.
4. Estabeleça as restrições técnicas (framework, performance, acessibilidade).
5. Pense na diferenciação: o que torna a interface inesquecível.
6. Implemente um código funcional, de nível de produção, visualmente marcante, coeso e meticulosamente refinado em todos os detalhes.
