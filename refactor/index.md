# Refatoração (Refactor)

Melhorar a estrutura e legibilidade do código sem alterar o comportamento externo.

## Resumo

1. **Para que serve:** Evolução gradual do código para melhorar a manutenção, clareza e facilitar a adição de novas funcionalidades.
2. **Comando de instalação:** `npx skills add github/awesome-copilot/refactor`
3. **Melhor forma de usar:** Fazer pequenas mudanças, utilizar controle de versão, garantir que existam testes essenciais e focar em uma coisa por vez.
