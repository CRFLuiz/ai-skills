# UI/UX Pro Max - Design Intelligence

A skill **UI/UX Pro Max** é um guia de inteligência de design abrangente para aplicações web e mobile, contendo uma vasta base de conhecimento para orientar escolhas de experiência de usuário e interface visual.

## Resumo

1. **Para que serve:** Fornece um banco de dados pesquisável com recomendações baseadas em prioridade para decisões de design visual, estrutura de interface, padrões de interação e controle de qualidade de UX. Inclui mais de 50 estilos, 161 paletas de cores, 57 combinações de fontes, 161 tipos de produtos, 99 diretrizes de UX e 25 tipos de gráficos em 10 stacks de tecnologia.
2. **Comando de Instalação:**
   ```bash
   npx skills add https://github.com/nextlevelbuilder/ui-ux-pro-max-skill --skill ui-ux-pro-max
   ```
3. **Melhor forma de usar:** Sempre que a tarefa envolver estrutura de UI, decisões de design visual, padrões de interação ou controle de qualidade da experiência do usuário, especialmente ao criar novas páginas, refatorar componentes ou escolher sistemas de cores/tipografia.
