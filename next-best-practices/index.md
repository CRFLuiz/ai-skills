# Next.js Best Practices

A skill **Next.js Best Practices** fornece diretrizes abrangentes para o desenvolvimento com Next.js, cobrindo estrutura de arquivos, padrões de React Server Components (RSC), busca de dados, otimização e tratamento de erros.

## Resumo

1. **Para que serve:** Serve como um guia oficial de melhores práticas para desenvolvimento em Next.js (versões 15+), cobrindo mais de 15 áreas de tópicos como convenções de arquivos, segmentos de rotas, limites de RSC, padrões assíncronos, geração de metadados, otimização de imagens e fontes, além de tratamento de erros de hidratação e roteamento avançado.
2. **Comando de Instalação:**
   ```bash
   npx skills add https://github.com/vercel-labs/next-skills --skill next-best-practices
   ```
3. **Melhor forma de usar:** Deve ser consultada sempre que estiver desenvolvendo ou revisando código Next.js. É ideal para garantir a correta aplicação de Server Components, rotas da API, otimizações nativas do framework e padrões recomendados de busca de dados e manipulação de erros.
