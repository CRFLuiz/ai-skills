# Code Review

Uma skill estruturada para revisar código, garantindo qualidade, segurança e performance em pull requests.

## Resumo

1. **Para que serve:** Revisar pull requests, verificar a qualidade do código, fornecer feedback sobre implementações, identificar potenciais bugs e sugerir melhorias.
2. **Comando de instalação:** `npx skills add supercent-io/skills-template/code-review`
3. **Melhor forma de usar:** Utilizar seguindo o passo a passo da revisão, analisando desde o contexto geral e a arquitetura até detalhes de código, segurança e testes, e por fim fornecer feedback construtivo e específico.
