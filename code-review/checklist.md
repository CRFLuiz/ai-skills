# Checklist de Revisão

## Funcionalidade

1. O código faz o que deve fazer.
2. Casos extremos foram tratados.
3. Casos de erro foram tratados.
4. Não há bugs óbvios.

## Qualidade do Código

1. Nomenclatura clara e descritiva.
2. As funções são pequenas e focadas.
3. Sem duplicação de código.
4. Consistente com o estilo da base de código.
5. Sem "code smells" (cheiros de código).

## Segurança

1. Validação de entradas realizada.
2. Sem segredos expostos no código.
3. Autenticação e autorização adequadas.
4. Sem vulnerabilidades de injeção SQL.
5. Sem vulnerabilidades XSS.

## Performance

1. Sem gargalos óbvios.
2. Algoritmos eficientes.
3. Consultas de banco de dados adequadas.
4. Gerenciamento correto de recursos.

## Testes

1. Testes foram incluídos.
2. Boa cobertura de testes.
3. Os testes são sustentáveis.
4. Casos extremos foram testados.

## Documentação

1. O código é auto-documentado.
2. Comentários foram adicionados onde necessário.
3. A documentação foi atualizada.
4. Alterações que quebram compatibilidade foram documentadas.
