# Mobile iOS Design

Skill focada no domínio das diretrizes de interface humana da Apple (HIG) e padrões do SwiftUI para construir aplicativos iOS nativos e polidos.

## Resumo

1. **Para que serve:** Serve para projetar interfaces de aplicativos iOS seguindo as diretrizes da Apple, construir layouts com SwiftUI, implementar navegação e criar interfaces acessíveis e adaptáveis.
2. **Comando de instalação:** `npx skills add wshobson/agents/mobile-ios-design`
3. **Melhor forma de usar:** Utilizar como referência ao desenhar interfaces iOS, consultando as práticas recomendadas para layouts, padrões de navegação e integração com o sistema (como Dynamic Type e Dark Mode).
