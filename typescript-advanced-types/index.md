# TypeScript Advanced Types

Orientação abrangente para dominar o sistema de tipos avançados do TypeScript, incluindo genéricos, tipos condicionais, tipos mapeados, tipos literais de template e tipos utilitários para construir aplicações robustas e seguras.

## Resumo

1. **Para que serve:** Construir bibliotecas tipadas, componentes genéricos reutilizáveis, lógica complexa de inferência de tipos, clientes de API e validações de formulário com segurança de tipos.
2. **Comando de instalação:** `npx skills add wshobson/agents/typescript-advanced-types`
3. **Melhor forma de usar:** Utilizar os conceitos centrais (Generics, Conditional Types, Mapped Types, etc.) em conjunto com padrões de projeto (ex: EventEmitter tipado, Builder, validação de formulários) para garantir que erros sejam pegos em tempo de compilação.
