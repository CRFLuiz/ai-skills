# Build, SSR e Avançado

## Build e SSR

1. **Modo Biblioteca (Library mode):** Empacotamento para bibliotecas.
2. **Modo Middleware SSR:** Configuração de servidor SSR integrado.
3. **ssrLoadModule:** Carregamento de módulos do lado do servidor.
4. **API JavaScript:** Interface de programação para build.

## Tópicos Avançados

1. **API de Ambiente (Environment API):** Suporte a múltiplos ambientes (Vite 6+) e runtimes customizados.
2. **Migração Rolldown:** Alterações introduzidas no Vite 8, incluindo o empacotador Rolldown, transformador Oxc e migração de configuração.
