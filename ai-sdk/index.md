# AI SDK

Skill para construção e consumo de aplicações baseadas em IA (LLMs, agentes) utilizando o AI SDK da Vercel. 

## Resumo

1. Para que serve: Oferecer padrões atualizados, documentação e ferramentas para implementar recursos de Inteligência Artificial de forma confiável e com segurança de tipos (Type Safety).
2. Comando de instalação: `npx skills add vercel/ai@ai-sdk` (Sendo o pacote do projeto instalado com `pnpm add ai` ou equivalente).
3. Melhor forma de usar: Evitando confiar na memória ou dados de treinamento antigos, buscando sempre a documentação mais recente localmente (`node_modules/ai/docs/`) ou na web, e usando o padrão `ToolLoopAgent` com o Vercel AI Gateway.
