# Design Thinking e Contexto

## Antes de Codificar

1. Entenda o contexto a partir dos requisitos fornecidos pelo usuário (componente, página, aplicação ou interface).
2. Comprometa-se com uma direção estética OUSADA.
3. **Propósito:** Qual problema essa interface resolve? Quem a utiliza?
4. **Tom:** Escolha um extremo (ex: brutalmente minimalista, caos maximalista, retro-futurista, orgânico/natural, luxuoso/refinado, lúdico, editorial/revista, brutalista/cru, art deco, pastel, industrial). Use esses exemplos como inspiração para um design autêntico.
5. **Restrições:** Entenda os requisitos técnicos (framework, performance, acessibilidade).
6. **Diferenciação:** O que torna a interface INESQUECÍVEL? Qual é a única coisa que alguém vai lembrar?

## Princípio Crítico

1. Escolha uma direção conceitual clara e execute-a com precisão. Tanto o maximalismo ousado quanto o minimalismo refinado funcionam — a chave é a intencionalidade, não a intensidade.
2. Implemente código funcional (HTML/CSS/JS, React, Vue, etc.) que seja de nível de produção.
3. O design deve ser visualmente marcante, coeso, com um ponto de vista estético claro e meticulosamente refinado em todos os detalhes.
