# Frontend Design (Claude Code)

Habilidade para orientar a criação de interfaces frontend distintas e de nível de produção, evitando a estética genérica gerada por IA ("AI slop").

## Resumo

1. **Para que serve:** Criar interfaces com atenção excepcional aos detalhes estéticos e escolhas criativas, garantindo que o design seja funcional, marcante e coeso.
2. **Comando de instalação:** `npx skills add anthropics/claude-code/frontend-design`
3. **Melhor forma de usar:** Antes de codificar, entenda o contexto (propósito, público) e comprometa-se com uma direção estética ousada (ex: brutalista, minimalista, retrô-futurista), focando na intencionalidade.
