# Find Skills

A skill **Find Skills** permite descobrir e instalar novas habilidades (skills) especializadas do ecossistema aberto diretamente no seu agente quando capacidades adicionais são necessárias.

## Resumo

1. **Para que serve:** Ajuda a identificar, verificar e instalar skills relevantes por domínio e tarefa (ex: "como faço X" ou "encontre uma skill para X").
2. **Comando de Instalação:**
  ```bash
  npx skills add https://github.com/vercel-labs/skills --skill find-skills
  ```
1. **Melhor forma de usar:** Sempre que você precisar de ajuda com uma tarefa específica e imaginar que já exista uma ferramenta ou fluxo de trabalho criado para isso. O ideal é primeiro entender o domínio da necessidade e depois usar o comando de busca.
