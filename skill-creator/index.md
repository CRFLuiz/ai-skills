# Skill Creator

A skill **Skill Creator** da Anthropics é uma ferramenta projetada para criar, testar e aprimorar iterativamente novas habilidades (skills) de agentes de IA usando avaliação estruturada e benchmarks.

## Resumo

1. **Para que serve:** Ela orienta o usuário através de todo o ciclo de vida de desenvolvimento de uma skill. Desde a captura da intenção, rascunho, criação de casos de teste, avaliação com resultados quantitativos e qualitativos, até a iteração baseada em feedback do usuário. Inclui a otimização de descrições para garantir que a skill seja ativada corretamente.
2. **Comando de Instalação:**
   ```bash
   npx skills add https://github.com/anthropics/skills --skill skill-creator
   ```
3. **Melhor forma de usar:** Sempre que você quiser desenvolver uma nova capacidade automatizada ou fluxo de trabalho estruturado para seu agente. O processo ajuda a definir claramente quando a skill deve ser acionada, como ela deve funcionar e testa os resultados em paralelo para garantir sua eficiência.
