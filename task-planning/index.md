# Planejamento de Tarefas (Task Planning)

Métodos para dividir novas funcionalidades em pequenas tarefas e organizar o trabalho de desenvolvimento.

## Resumo

1. **Para que serve:** Organizar o desenvolvimento de funcionalidades, planejar sprints e refinar o backlog.
2. **Comando de instalação:** `npx skills add https://github.com/supercent-io/skills-template --skill task-planning`
3. **Melhor forma de usar:** Escrever histórias de usuário utilizando o princípio INVEST, quebrar as histórias em tarefas menores e priorizar utilizando o método MoSCoW.
