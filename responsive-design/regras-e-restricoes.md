# Regras e Restrições

## Pontos de Interrupção Padrão (Breakpoints)

1. Mobile (padrão): 320px até 767px.
2. Tablet: 768px até 1023px.
3. Desktop: 1024px até 1439px.
4. Telas Grandes: acima de 1440px.

## Regras Obrigatórias

1. **Meta Tag de Viewport:** A tag `<meta name="viewport" content="width=device-width, initial-scale=1.0">` deve estar presente no HTML.
2. **Mobile-First:** O estilo padrão deve ser para mobile, utilizando `min-width` nas media queries.
