# Design Responsivo (Responsive Design)

Diretrizes para criar layouts responsivos que funcionam bem em dispositivos móveis e desktops.

## Resumo

1. **Para que serve:** Criar ou melhorar layouts para que se adaptem a diferentes tamanhos de tela e otimizar o carregamento de imagens por dispositivo.
2. **Comando de instalação:** `npx skills add supercent-io/skills-template/responsive-design`
3. **Melhor forma de usar:** Adotar a abordagem Mobile-First, utilizando Flexbox e CSS Grid para estruturar o layout.
