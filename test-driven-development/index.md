# Test-Driven Development (TDD)

Metodologia de desenvolvimento baseada na escrita de testes antes da implementação do código. 

## Resumo

1. **Para que serve:** Garantir que o código atenda aos requisitos esperados escrevendo primeiro um teste que falha, para então implementar o código mínimo necessário para fazê-lo passar.
2. **Comando de instalação:** `npx skills add obra/superpowers/test-driven-development`
3. **Melhor forma de usar:** Aplicar o ciclo Red-Green-Refactor (Escrever teste que falha, fazer passar com o mínimo de código, e então refatorar) para todas as novas funcionalidades, correções de bugs e refatorações.
