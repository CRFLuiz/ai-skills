# Shadcn UI (Component Integration)

Especialidade focada na integração, descoberta e customização de componentes da biblioteca shadcn/ui, utilizando Radix UI ou Base UI e Tailwind CSS.

## Resumo

1. **Para que serve:** Auxiliar desenvolvedores na integração de componentes acessíveis e personalizáveis, onde o código-fonte vive no próprio projeto, oferecendo controle total sobre estilo e comportamento.
2. **Comando de instalação:** `npx skills add google-labs-code/stitch-skills/shadcn-ui`
3. **Melhor forma de usar:** Utilizar a CLI para adicionar componentes diretamente (`npx shadcn@latest add`), personalizar temas no `globals.css` e compor blocos complexos usando o utilitário `cn()` para mesclagem inteligente de classes Tailwind.
