# React Native Best Practices

Guia de otimização de desempenho para aplicativos React Native, cobrindo otimizações em JavaScript/React, Nativo (iOS/Android) e empacotamento (bundling). Baseado no "Guia Definitivo para Otimização em React Native" da Callstack.

## Resumo

1. **Para que serve:** Serve para diagnosticar e resolver problemas de lentidão, travamentos na interface, vazamentos de memória e tempo de inicialização lento, além de otimizar o tamanho do aplicativo e o desempenho do código nativo.
2. **Comando de instalação:** `npx skills add callstackincubator/agent-skills/react-native-best-practices`
3. **Melhor forma de usar:** Utilizar seguindo o ciclo de fluxo de trabalho de otimização: Medir o estado atual, Otimizar aplicando a correção sugerida, Medir novamente e Validar a melhoria. Pode ser consultado em casos específicos, como listas lentas, alto uso de memória ou lentidão em animações.
