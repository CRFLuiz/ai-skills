# Frontend Design System

Skill focada na criação de interfaces de usuário (UI) de qualidade para produção, suportando um desenvolvimento frontend escalável e consistente através de design tokens claros, regras de layout, diretrizes de animação e verificações de acessibilidade.

## Resumo

1. **Para que serve:** Serve para gerar interfaces de alta qualidade a partir de prompts, manter uma linguagem visual unificada através de telas (usando design tokens) e fornecer orientações sistemáticas de tipografia, layout e animação (motion).
2. **Comando de instalação:** `npx skills add supercent-io/skills-template/frontend-design-system`
3. **Melhor forma de usar:** Utilizar como um guia passo a passo durante a concepção de interfaces, começando pela definição dos tokens de design, passando pelo planejamento do layout, geração de código, até a validação final de acessibilidade.
