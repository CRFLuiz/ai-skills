# Escopo e Pré-requisitos

1. **Escopo de Aplicação**
   1. Sites estáticos (HTML/CSS/JS).
   2. Frameworks SPA como React, Vue, Angular e Svelte.
   3. Frameworks Full-stack como Next.js, Nuxt e SvelteKit.
   4. Plataformas CMS como WordPress e Drupal.
   5. Qualquer outra aplicação web.

2. **Pré-requisitos Obrigatórios**
   1. **Site alvo deve estar em execução:** Seja um servidor de desenvolvimento local (ex: http://localhost:3000), um ambiente de staging ou ambiente de produção (apenas para revisões de leitura).
   2. **Automação de navegador disponível:** É necessário possuir capacidades de captura de tela, navegação de páginas e obtenção de informações do DOM (ex: usando Playwright MCP).
   3. **Acesso ao código-fonte (para correções):** O projeto deve existir dentro do seu ambiente de trabalho (workspace) para que as modificações sejam aplicadas.

3. **Capacidades Necessárias**
   1. Navegação em páginas web (obrigatório).
   2. Captura de telas para inspeção visual (obrigatório).
   3. Análise de imagens para detecção de problemas visuais (obrigatório).
   4. Recuperação do DOM (recomendado).
   5. Leitura e escrita de arquivos para edição de código (obrigatório para correções).
   6. Pesquisa de código no projeto (obrigatório para correções).
