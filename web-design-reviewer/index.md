# Web Design Reviewer

Skill que permite a inspeção visual e validação da qualidade do design de sites, identificando e corrigindo problemas no nível do código-fonte.

## Resumo

1. **Para que serve:** Serve para revisar sites em diferentes resoluções, identificar problemas de layout (como sobreposição de elementos), responsividade e acessibilidade, e aplicar correções no código usando automação de navegador (ex: Playwright MCP).
2. **Comando de instalação:** `npx skills add github/awesome-copilot/web-design-reviewer`
3. **Melhor forma de usar:** Utilizar quando um site já estiver rodando localmente (ou em staging/produção) para buscar erros de alinhamento, responsividade e contraste, permitindo que a skill faça inspeções e proponha ou aplique correções seguindo um fluxo de trabalho estruturado.
