# Início Rápido e Fluxo Principal

## Como Conectar

1. Conecte-se a uma sessão de navegador já existente (exemplo: porta 9222). Isso é mais rápido do que abrir um novo navegador.
2. Alternativamente, abra o Slack usando a URL oficial se não estiver em execução.
3. Após conectar, tire um snapshot para ver os elementos interativos disponíveis.

## Fluxo de Trabalho Principal

1. **Conectar/Navegar:** Abra ou conecte-se ao Slack.
2. **Snapshot:** Obtenha elementos interativos com suas referências.
3. **Navegar:** Clique em abas, expanda seções ou navegue para canais específicos.
4. **Extrair/Interagir:** Leia dados ou realize ações.
5. **Capturar Tela (Screenshot):** Registre evidências das suas descobertas.
