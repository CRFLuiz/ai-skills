# Estrutura e Boas Práticas

## Estrutura da Barra Lateral

1. Threads, Huddles, Rascunhos.
2. Diretórios e Cabeçalhos de Seção.
3. Canais (listados como itens em árvore).
4. Mensagens Diretas.
5. Atalhos de Aplicativos.
6. Botão para alternar a lista de canais não lidos.

## Boas Práticas

1. Conecte-se a sessões existentes para economizar tempo.
2. Sempre tire snapshots antes de clicar para identificar as referências corretas.
3. Tire um novo snapshot após cada navegação.
4. Use snapshots em JSON quando precisar extrair dados estruturados.
5. Adicione pequenos atrasos entre interações rápidas para permitir a atualização da interface.

## Limitações

1. A ferramenta usa automação de navegador, não a API do Slack.
2. Imagens e snapshots estão vinculados à sessão atual do navegador.
3. O Slack pode limitar interações muito rápidas.
4. A automação é específica para o seu espaço de trabalho atual.
