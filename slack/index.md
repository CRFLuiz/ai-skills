# Automação do Slack (Slack Automation)

Interaja com espaços de trabalho do Slack para verificar mensagens, extrair dados e automatizar tarefas comuns através do navegador.

## Resumo

1. **Para que serve:** Conectar ao Slack para ler canais, checar mensagens não lidas e capturar dados do estado atual.
2. **Comando de instalação:** `npx skills add vercel-labs/agent-browser/slack`
3. **Melhor forma de usar:** Conectar a uma sessão existente no navegador e usar snapshots de acessibilidade para obter as referências corretas antes de clicar.
