# Vercel React Best Practices

A skill **Vercel React Best Practices** é um guia abrangente de otimização de performance para aplicações React e Next.js, mantido pela Engenharia da Vercel.

## Resumo

1. **Para que serve:** Contém 69 regras organizadas em 8 categorias priorizadas por impacto (de crítico a baixo). Auxilia no processo de refatoração, code review e escrita de componentes, abordando temas como waterfalls, otimização de bundle, SSR, re-renderização, performance do JS e muito mais.
2. **Comando de Instalação:**
  ```bash
  npx skills add https://github.com/vercel-labs/agent-skills --skill vercel-react-best-practices
  ```
1. **Melhor forma de usar:** Acione esta skill durante a criação de novos componentes, ao revisar o código para evitar gargalos de performance, ao refatorar aplicações ou ao tentar reduzir o tamanho do bundle (bundle size) de projetos React/Next.js.
