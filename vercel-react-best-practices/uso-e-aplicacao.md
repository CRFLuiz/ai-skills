# Uso e Aplicação: Vercel React Best Practices

A skill **Vercel React Best Practices** é um guia estruturado projetado para ajudar a orientar a refatoração automatizada e a geração de código otimizado no ecossistema React e Next.js.

## Quando Aplicar

Consulte estas diretrizes (ou invoque a skill) nos seguintes cenários:

1. **Escrevendo Novos Componentes:** Ao criar novos componentes React ou páginas Next.js.
2. **Implementando Fetching de Dados:** Seja no client-side (navegador) ou no server-side (servidor).
3. **Code Reviews:** Ao revisar código em busca de problemas de performance, waterfalls (bloqueios em cadeia) ou lentidão.
4. **Refatoração:** Ao refatorar código React/Next.js existente para melhorar a legibilidade e desempenho.
5. **Otimização:** Ao buscar reduzir o tamanho do pacote (bundle size) ou diminuir os tempos de carregamento (load times).

## Como Usar

A melhor forma de explorar e aplicar estas regras é consultar os arquivos individuais de cada regra (por exemplo, `rules/async-parallel.md`). 

Cada regra documentada contém:
1. **Breve Explicação:** Por que a regra é importante e o impacto que causa na performance.
2. **Exemplo Incorreto:** Como o código costuma ser escrito erroneamente.
3. **Exemplo Correto:** Como o código deve ser reescrito com a explicação do motivo.
4. **Contexto Adicional:** Referências para a documentação oficial ou discussões técnicas aprofundadas.

*Você pode conferir a lista completa de regras dividida por categorias no arquivo [Diretrizes de Performance](./diretrizes-de-performance.md).*
