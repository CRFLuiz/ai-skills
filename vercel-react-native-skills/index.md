# Vercel React Native Skills

Práticas recomendadas abrangentes para aplicativos React Native e Expo.

## Resumo

1. **Para que serve:** Fornecer um conjunto de regras e melhores práticas abrangendo desempenho, animações, padrões de interface e otimizações específicas de plataforma para React Native.
2. **Comando de instalação:** `npx skills add vercel-labs/agent-skills/vercel-react-native-skills`
3. **Melhor forma de usar:** Utilizar como referência contínua durante o desenvolvimento de aplicativos React Native ou Expo, especialmente ao lidar com performance de listas, animações, gerenciamento de estado e estrutura de monorepo.
