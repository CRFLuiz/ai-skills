# Shadcn UI

Um framework para construir interfaces de usuário (UI), componentes e design systems, adicionando o código-fonte diretamente ao projeto via CLI.

## Resumo

1. **Para que serve:** Adicionar componentes de UI acessíveis e customizáveis ao seu projeto copiando o código fonte, permitindo controle total sobre a implementação e o estilo.
2. **Comando de instalação:** `npx shadcn@latest init` (para iniciar) e `npx shadcn@latest add <componente>` (para adicionar).
3. **Melhor forma de usar:** Sempre rodar comandos CLI utilizando o gerenciador de pacotes do projeto, usar componentes existentes antes de criar novos, compor interfaces a partir de partes menores e usar cores semânticas (ex: `bg-primary`) em vez de valores brutos.
