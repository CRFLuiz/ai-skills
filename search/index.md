# Search (Tavily AI)

Uma skill para realizar pesquisas na web e obter resultados relevantes e otimizados para consumo por Modelos de Linguagem (LLMs).

## Resumo

1. **Para que serve:** Realizar buscas na internet, extrair conteúdos de páginas, filtrar por domínios e ajustar a profundidade da pesquisa para obter dados precisos.
2. **Comando de instalação:** `npx skills add tavily-ai/skills/search`
3. **Melhor forma de usar:** Utilizar o script fornecido ou a API com autenticação, passando consultas curtas e diretas, e utilizando filtros (como domínios e intervalo de tempo) para aprimorar os resultados.
