# GitHub Actions Docs

Especialidade para consultar a documentação oficial do GitHub Actions e fornecer respostas baseadas em páginas autorizadas em vez de conselhos genéricos sobre CI/CD.

## Resumo

1. **Para que serve:** Responder a perguntas sobre conceitos, sintaxe, runners, segurança, implantações e migração relacionados ao GitHub Actions, fundamentando-se sempre na documentação oficial.
2. **Comando de instalação:** `npx skills add xixu-me/skills/github-actions-docs`
3. **Melhor forma de usar:** Usar para dúvidas de sintaxe e conceitos do Actions, evitando utilizar para triagem de falhas específicas de CI (usar `gh-fix-ci`), operações gerais do GitHub, CodeQL ou configuração do Dependabot.
