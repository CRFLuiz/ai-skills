# Quando Usar e Fluxo de Trabalho

## Quando Usar

1. Use para conceitos do GitHub Actions, terminologia ou limites do produto.
2. Dúvidas sobre YAML de fluxo de trabalho, gatilhos, jobs, matrizes, concorrência, variáveis, contextos ou expressões.
3. Questões sobre runners hospedados no GitHub, runners maiores, runners auto-hospedados ou Actions Runner Controller.
4. Para artefatos, caches, fluxos de trabalho reutilizáveis, modelos de fluxo de trabalho ou ações personalizadas.
5. Para segredos, `GITHUB_TOKEN`, OpenID Connect (OIDC), atestados de artefatos ou padrões de fluxo de trabalho seguros.
6. Sobre ambientes, regras de proteção de implantação, histórico e exemplos de implantação.
7. Migração de Jenkins, CircleCI, GitLab CI/CD, Travis CI, Azure Pipelines, etc.
8. Solução de problemas de comportamento de fluxo de trabalho quando o usuário precisar de documentação, guia de sintaxe ou referências oficiais.
9. Não use para triagem de falhas de CI específicas (use `gh-fix-ci`), operações gerais do GitHub (use `github`), CodeQL ou Dependabot.

## Fluxo de Trabalho

1. Classifique a solicitação antes de pesquisar (ex: introdução, sintaxe, runners, segurança, implantações, etc.).
2. Pesquise primeiro na documentação oficial do GitHub (`docs.github.com/en/actions`), usando termos exatos do usuário mais uma frase focada em Actions.
3. Compare 2 ou 3 páginas candidatas e escolha a que responder de forma mais direta.
4. Abra a melhor página antes de responder e leia a seção exata quando for prático.
5. Se uma página parecer renomeada, movida ou incompleta, diga isso explicitamente e retorne as páginas autorizadas mais próximas.
6. Responda com orientações fundamentadas na documentação. Comece com uma resposta direta em linguagem simples.
7. Inclua links exatos da documentação do GitHub, não apenas a página inicial.
8. Forneça YAML ou exemplos passo a passo apenas se solicitado ou se a página tornar o exemplo necessário.
9. Torne qualquer inferência explícita (ex: "Segundo a documentação do GitHub... Inferência: isso provavelmente significa...").
