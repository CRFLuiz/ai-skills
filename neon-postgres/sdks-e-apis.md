# SDKs, APIs e CLI

1. O **Neon REST API** permite automação direta via HTTP, controle a nível de endpoints, autenticação via API key, tratamento de rate-limits e "polling" de operações.
2. A **Neon Admin API** é usada internamente pela CLI do Neon e pelo servidor MCP, mas pode ser utilizada para fluxos de automação mais complexos ou para embarcar o Neon em outras aplicações.
3. Para controle programático tipado de recursos do Neon em TypeScript, o **Neon TypeScript SDK** (`@neondatabase/api-client`) é a escolha correta.
4. Desenvolvedores em Python podem usar o pacote `neon-api` através do **Neon Python SDK** para gerenciamento programático.
5. A **Neon CLI** (`neonctl`) é ideal para fluxos orientados a terminal, scripts e automação de CI/CD.
6. A plataforma também disponibiliza o **Neon Auth** para configuração de autenticação gerenciada de usuários, embora essas funcionalidades também estejam embutidas no Neon JS SDK.
