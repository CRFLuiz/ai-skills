# Neon Postgres

Skill focada em gerenciar ambientes de Neon Serverless Postgres, uma plataforma Postgres serverless que separa computação e armazenamento para oferecer autoscaling, ramificação (branching), restauração instantânea e scale-to-zero.

## Resumo

1. Para que serve: Integrar, gerenciar e otimizar conexões com o Neon Postgres de forma programática, facilitando automações de CI/CD, ramificação de banco de dados (branching) e escalonamento dinâmico.
2. Comando de instalação: `npx skills add neondatabase/agent-skills@neon-postgres`
3. Melhor forma de usar: Aproveitando a arquitetura serverless para criar "branches" isoladas para testes e utilizando os drivers otimizados (HTTP/WebSocket) em ambientes serverless ou edge.
