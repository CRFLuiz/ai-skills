# Web Design Guidelines

A skill **Web Design Guidelines** da Vercel realiza uma auditoria no código de interface do usuário (UI) para garantir a conformidade com as melhores práticas de design e acessibilidade.

## Resumo

1. **Para que serve:** Ela busca as diretrizes mais recentes remotamente e audita o código (mais de 100 regras) avaliando acessibilidade, performance e UX. A saída é entregue num formato conciso (`arquivo:linha`) para rápida visualização e correção.
2. **Comando de Instalação:**
  ```bash
  npx skills add https://github.com/vercel-labs/agent-skills --skill web-design-guidelines
  ```
1. **Melhor forma de usar:** Sempre que quiser revisar o código de UI para verificar aderência às melhores práticas de design web. Exemplo: *"Revise minha UI"*, *"Verifique a acessibilidade"*, *"Audite o design"* ou *"Revise a UX"*.
