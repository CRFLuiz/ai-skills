# Web Search

Skill responsável por pesquisar na web e extrair conteúdo utilizando a interface de linha de comando (CLI) do inference.sh (`infsh`).

## Resumo

1. Para que serve: Realizar buscas na internet, obter respostas factuais, extrair conteúdos de URLs (textos e imagens) e fornecer dados em fluxos de RAG (Retrieval-Augmented Generation) integrados com modelos LLM.
2. Comando de instalação: `npx skills add inferen-sh/skills@web-search` (ou para todas as aplicações: `npx skills add inference-sh/skills@infsh-cli`).
3. Melhor forma de usar: Utilizando a CLI do `infsh` para fazer buscas e encadear os resultados JSON em prompts para modelos de linguagem (ex: analisar artigos ou criar resumos).
