# Skills

Este repositório contém uma coleção de skills, boas práticas e guias de referência para diversas áreas de desenvolvimento, design e marketing. Abaixo, as skills estão organizadas por categorias.

## Desenvolvimento Frontend & UI/UX

### [Chat UI](./chat-ui/index.md)
Diretrizes e componentes para construção de interfaces de chat modernas e responsivas. Aborda melhores práticas de UX para interações em tempo real, gerenciamento de estado e exibição de histórico de mensagens.

### [Design Responsivo (Responsive Design)](./responsive-design/index.md)
Princípios e técnicas fundamentais para criar layouts que se adaptam perfeitamente a diferentes tamanhos de tela. Foca no uso de media queries, flexbox, CSS grid e abordagens mobile-first.

### [Frontend Design](./frontend-design/index.md)
Boas práticas gerais para o desenvolvimento de interfaces frontend atraentes e funcionais. Inclui dicas essenciais sobre acessibilidade, usabilidade e consistência visual ao longo da aplicação.

### [Frontend Design (Claude Code)](./claude-code-frontend-design/index.md)
Diretrizes específicas de design frontend focadas no ecossistema e nas ferramentas do Claude. Orientado para acelerar o desenvolvimento de interfaces integradas com inteligência artificial.

### [Frontend Design System](./frontend-design-system/index.md)
Como estruturar, documentar e manter um Design System eficiente no frontend. Garante consistência, reutilização de componentes e um alinhamento claro entre as equipes de design e código.

### [Mobile iOS Design](./mobile-ios-design/index.md)
Padrões e diretrizes de interface especificamente voltados para o ecossistema iOS. Segue os princípios do Human Interface Guidelines (HIG) da Apple para garantir uma experiência nativa.

### [Shadcn UI](./shadcn/index.md)
Guia de uso e customização da biblioteca Shadcn UI no desenvolvimento de interfaces. Focado na criação de componentes acessíveis e altamente personalizáveis usando Tailwind CSS.

### [Shadcn UI (Component Integration)](./shadcn-ui/index.md)
Técnicas avançadas para integração e composição de componentes do Shadcn UI em projetos complexos. Facilita a escalabilidade da interface mantendo a coesão visual em todas as páginas.

### [UI/UX Pro Max - Design Intelligence](./ui-ux-pro-max/index.md)
Conceitos avançados de UI/UX com foco em inteligência de design e comportamento do usuário. Explora como criar experiências altamente imersivas, preditivas e focadas na conversão.

### [Web Design Guidelines](./web-design-guidelines/index.md)
Regras e padrões gerais essenciais para o web design moderno. Cobre fundamentos vitais como tipografia, teoria das cores, uso de espaçamento e hierarquia visual.

### [Web Design Reviewer](./web-design-reviewer/index.md)
Ferramentas e processos para revisar a qualidade do web design de forma sistemática e rigorosa. Ajuda a identificar problemas de usabilidade, acessibilidade e inconsistências estéticas antes do lançamento.

## Frameworks & Ecossistema

### [Expo API Routes](./expo-api-routes/index.md)
Como utilizar rotas de API dentro do ecossistema Expo para desenvolvimento mobile e web. Ideal para criar endpoints de backend leves e integrados diretamente ao seu aplicativo React Native.

### [Next.js Best Practices](./next-best-practices/index.md)
Padrões recomendados, otimizações de performance e arquitetura ideal para projetos em Next.js. Aborda Server Components, roteamento avançado e estratégias eficientes de rendering (SSR/SSG).

### [React Native Best Practices](./react-native-best-practices/index.md)
Recomendações arquiteturais e de performance para aplicativos móveis construídos com React Native. Foca em gerenciamento de estado estruturado, navegação fluida e otimização de renderização.

### [Vercel React Best Practices](./vercel-react-best-practices/index.md)
Melhores práticas para desenvolvimento React otimizado para a plataforma de hospedagem da Vercel. Inclui estratégias de caching, uso de edge functions e otimização automatizada de imagens.

### [Vercel React Native Skills](./vercel-react-native-skills/index.md)
Integração e práticas recomendadas para projetos React Native dentro do ecossistema de ferramentas da Vercel. Ajuda a conectar aplicativos móveis aos serviços de nuvem de forma eficiente.

### [Vite](./vite/index.md)
Guia de configuração, otimização e uso avançado do Vite como bundler para projetos frontend modernos. Ensina como tirar o máximo proveito do Hot Module Replacement (HMR) ultrarrápido e builds otimizados.

## Backend & Banco de Dados

### [Database Schema Design](./database-schema-design/index.md)
Princípios essenciais para a modelagem eficiente de bancos de dados relacionais e não relacionais. Foca em normalização correta, integridade dos dados e design focado em alta performance.

### [Neon Postgres](./neon-postgres/index.md)
Como integrar e otimizar o uso do Neon, um moderno banco de dados PostgreSQL serverless. Aborda recursos como branching de dados, conexões escaláveis e configurações para alta disponibilidade.

## Engenharia de Software & Boas Práticas

### [Code Review](./code-review/index.md)
Diretrizes para conduzir revisões de código de forma construtiva, eficiente e empática. Ajuda as equipes a manter a qualidade da base de código enquanto compartilham conhecimento técnico.

### [Desenvolvimento Orientado a Testes (TDD)](./tdd/index.md)
Conceitos fundamentais e o fluxo prático da abordagem TDD (Test-Driven Development). Foca no ciclo iterativo de Red-Green-Refactor para garantir a construção de um software mais resiliente.

### [Refatoração (Refactor)](./refactor/index.md)
Técnicas seguras para melhorar a estrutura do código sem alterar seu comportamento externo. Essencial para lidar com dívida técnica, facilitar a manutenção e melhorar a legibilidade.

### [Test-Driven Development (TDD)](./test-driven-development/index.md)
Aprofundamento prático nas práticas de TDD, abordando cenários complexos, uso de mocks e integração contínua. Ajuda a consolidar uma cultura forte de testes automatizados desde a concepção da feature.

### [TypeScript Advanced Types](./typescript-advanced-types/index.md)
Exploração de recursos avançados do sistema de tipos do TypeScript para desenvolvedores experientes. Inclui tipos utilitários, condicionais, mapeados e inferência complexa para garantir type safety estrito.

## DevOps, CI/CD & Versionamento

### [Deploy to Vercel](./deploy-to-vercel/index.md)
Fluxo passo a passo para realizar deploys otimizados e seguros na infraestrutura da Vercel. Cobre a gestão de variáveis de ambiente, ambientes de preview e integrações contínuas.

### [Git Commit (Conventional Commits)](./git-commit/index.md)
Padrões e regras para escrever mensagens de commit semânticas usando a especificação do Conventional Commits. Facilita a geração de changelogs automatizados e o rastreamento histórico do projeto.

### [GitHub Actions Docs](./github-actions-docs/index.md)
Como criar, gerenciar e otimizar pipelines completos de CI/CD utilizando o GitHub Actions. Inclui automação de testes, processos de linting, builds eficientes e deploys automatizados.

## Inteligência Artificial & Agentes

### [AI SDK](./ai-sdk/index.md)
Guias e referências técnicas para integrar kits de desenvolvimento de inteligência artificial em suas aplicações. Facilita a conexão direta com modelos de linguagem (LLMs) e o gerenciamento eficiente de prompts.

### [Find Skills](./find-skills/index.md)
Estratégias e ferramentas para descobrir, avaliar e incorporar novas habilidades (skills) em sistemas baseados em agentes de IA. Ajuda a expandir a utilidade dos seus assistentes automatizados.

### [Search (Tavily AI)](./search/index.md)
Como implementar e utilizar as capacidades de busca avançada da Tavily AI em seus projetos. Focado em obter resultados de pesquisa precisos e estruturados, otimizados para o consumo por agentes inteligentes.

### [Skill Creator](./skill-creator/index.md)
Metodologia e passos práticos para criar novas "skills" personalizadas para assistentes e agentes de IA. Permite expandir consideravelmente as capacidades de ferramentas e orquestradores autônomos.

### [Subagent-Driven Development](./subagent-driven-development/index.md)
Padrões arquiteturais para construir sistemas baseados em múltiplos subagentes de IA altamente especializados. Foca na orquestração, comunicação eficiente entre agentes e delegação inteligente de tarefas.

### [Web Search](./web-search/index.md)
Técnicas para extração de dados e integração de mecanismos de busca web gerais em fluxos de IA. Melhora a capacidade do agente de encontrar informações relevantes e atualizadas em tempo real.

## Marketing, SEO & Conteúdo

### [Ad Creative](./ad-creative/index.md)
Estratégias e boas práticas para a criação de criativos de anúncios focados em alta conversão. Aborda desde o copywriting persuasivo até o design visual otimizado para tráfego pago.

### [Copywriting](./copywriting/index.md)
Técnicas de escrita persuasiva voltadas para impulsionar vendas, engajamento e retenção de usuários. Foca no uso de gatilhos mentais, clareza na mensagem e adequação do tom de voz da marca.

### [Marketing Ideas for SaaS](./marketing-ideas/index.md)
Estratégias inovadoras e validadas para a aquisição e retenção de clientes em negócios SaaS (Software as a Service). Inclui táticas de growth hacking, marketing de conteúdo e criação de loops virais.

### [Pricing Strategy](./pricing-strategy/index.md)
Modelos e táticas avançadas para definir a precificação ideal de produtos digitais e serviços SaaS. Aborda análise de concorrência, precificação baseada em valor percebido e estruturação de tiers.

### [Product Marketing Context](./product-marketing-context/index.md)
Como alinhar perfeitamente o desenvolvimento de produto com as necessidades reais de marketing e vendas. Essencial para garantir lançamentos bem-sucedidos e um posicionamento claro no mercado.

### [Programmatic SEO](./programmatic-seo/index.md)
Como escalar a criação de páginas e a otimização para motores de busca utilizando dados em massa e automação. Ideal para gerar tráfego qualificado focando em milhares de palavras-chave de cauda longa (long-tail).

### [SEO/GEO Optimization](./seo-geo/index.md)
Técnicas de SEO tradicional combinadas estrategicamente com otimização geográfica (Local SEO). Ajuda a aumentar significativamente a visibilidade orgânica tanto em nível global quanto em regiões específicas.

### [Social Content](./social-content/index.md)
Estratégias completas para criação, curadoria e distribuição eficiente de conteúdo em redes sociais. Foca em maximizar o engajamento do público e construir uma comunidade fiel e ativa em torno da marca.

### [Brainstorming](./brainstorming/index.md)
Técnicas e frameworks estruturados para facilitar sessões de ideação criativa e resolução complexa de problemas. Ajuda as equipes a gerar, organizar e priorizar ideias inovadoras de forma colaborativa.

### [Design MD](./design-md/index.md)
Padrões e convenções para estruturar documentações técnicas e de design utilizando a linguagem Markdown. Facilita a comunicação assíncrona da equipe e o registro histórico de decisões de arquitetura e UI.

### [Planejamento de Tarefas (Task Planning)](./task-planning/index.md)
Metodologias eficazes para quebrar projetos complexos em tarefas gerenciáveis e priorizá-las corretamente. Aborda todo o ciclo de vida da tarefa, desde a sua concepção inicial até a entrega final.

### [Writing Plans](./writing-plans/index.md)
Boas práticas essenciais para redigir planos de execução, propostas técnicas detalhadas e roteiros de projeto. Foca na clareza da comunicação, alinhamento de expectativas com stakeholders e definição precisa de escopo.
